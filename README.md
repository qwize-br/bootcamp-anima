# 🚀 Bootcamp DTCOM × QWize — Crie produtos com IA, sem saber programar

Bem-vindo(a)! Este repositório é o ponto de partida do **seu** projeto no bootcamp.
Você vai usar o mesmo kit e o mesmo processo que a **QWize usa em projetos reais** — e a IA faz o trabalho pesado. Você só responde as perguntas.

---

## O que você precisa (só 2 coisas)

1. **Conta no GitHub** ([github.com](https://github.com)) — gratuita
2. **Conta de IA** — qualquer uma dessas:
   - **Codex Student** (OpenAI)
   - **Google Antigravity**

> Não precisa instalar nada no seu computador. O agente de IA faz tudo dentro do seu repositório.

---

## Passo a passo

### 1️⃣ Crie o SEU repositório a partir deste template
- No topo desta página, clique em **`Use this template`** → **`Create a new repository`**
- Dê um nome ao seu projeto (ex.: `meu-projeto-bootcamp`) e clique em **Create repository**

### 2️⃣ Abra seu repositório no Codex ou no Antigravity
- Conecte sua conta de IA ao GitHub (se pedir) e abra o repositório que você acabou de criar

### 3️⃣ Cole o prompt pronto
- Abra o arquivo **`COMECE-AQUI.md`** deste repositório
- Copie o prompt de lá, complete com **a ideia do seu projeto** e cole no agente

### 4️⃣ Deixe a IA trabalhar 🤖
O agente vai:
- **Instalar o Wize Dev Kit** (leva ~2 minutos — é a mesma ferramenta que a QWize usa em produção)
- **Entrevistar você** sobre a sua ideia — uma pergunta por vez, em português
- Gerar o **brief** do projeto (`.wize/planning/brief.md`)

> ✅ **Checkpoint da Prática 1:** repo com o kit instalado + brief gerado.

### 5️⃣ Prática 2 — do brief ao plano executável
Peça ao agente para evoluir do brief para o **PRD com critérios de aceite** (e, se der tempo, épicos e stories).
- Não trouxe ideia própria? Use o **caso modelo** do Simulado do ENEM versão Web (pasta `caso-modelo/`)

> ✅ **Checkpoint da Prática 2:** PRD cobrindo o problema, com critérios de aceite claros.

### 6️⃣ Entrega final
- O **link do seu repositório** é a sua entrega (o kit + o brief/PRD ficam salvos nele)
- Prepare um **pitch de 1 minuto**: qual problema você escolheu → como a especificação o resolve → qual é o próximo passo

---

## Se travar

- **Erro na instalação?** Copie a mensagem de erro e cole no agente — peça para ele corrigir e repetir. Faz parte do processo.
- **Dúvida?** Chame o time DTCOM × QWize no chat do bootcamp (Nagar está por lá).
- **Ideia em branco?** Use o caso modelo: peça ao agente *"use o caso modelo da pasta caso-modelo/ como base do brief"*.
