# Story: Lista contínua de questões resolvidas com contraste visual de acerto/erro

## Context
Apresenta a lista corrida das 90 questões com destaque em vermelho para o erro cometido pelo aluno e em verde para o gabarito oficial.

## Acceptance criteria
- **AC-05-1:** Dado que o estudante clica em "Revisar Questões" a partir do resultado, Quando a tela de revisão abre, Então visualiza uma lista contínua com as questões resolvidas, destacando a resposta selecionada pelo estudante (vermelho se errou) e o gabarito oficial (verde).

## Done means
Itens de revisão exibidos com classes status-correct, status-wrong e justificativa didática.
